# Codex Resets — launch copy (draft only)

This is a local draft. It has not been posted or scheduled anywhere.

## English

Codex Resets is a small public dashboard for checking the estimated timing of
the next Codex usage-limit reset. It stays lightweight, works without an
account, and can send an optional email or browser reminder after confirmation.

https://codexresets.cc

## 中文

Codex Resets 是一个轻量的 Codex 使用额度重置预测面板：无需注册即可查看估计时间，也可以在确认后订阅邮件或浏览器提醒。

https://codexresets.cc
